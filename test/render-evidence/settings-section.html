如何修改
这些值来自 profile 的 cordis.patch.yml。本页只读 —— 插件不会替你改配置文件（写回 YAML 会破坏注释、和插件管理器的写入互相覆盖，风险高于收益）。
改法：复制下面的片段 → 粘到你的 profile 里 → 保存，宿主会热重载。
- insert:
    - id: provider-console
      name: dsh-plugin-provider-console
      config:
        autoDiscover: true
        lowBalanceThreshold: 20
        cacheTtlMs: 60000
        dashboard:
          enabled: true
          port: 8788
        sidebar:
          enabled: true
          label: 服务商控制台
          order: 20
        llmProvider:
          enabled: true
